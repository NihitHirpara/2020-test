# TenTwenty Farms

Custom Shopify theme layer (`tt-*`) built on Horizon.

Store: https://2020-test-wlq3sh03.myshopify.com

`theme/` — custom sections, snippets, assets, and templates (home, product, collection).

- Product listing: `/collections/all-farm-goods` with **Category** + **Color** filters
- SEO: JSON-LD (Product, BreadcrumbList, Organization, WebSite)
